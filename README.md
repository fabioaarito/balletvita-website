## Aula Experimental form

The "Aula Experimental" form is available at `/aula-experimental` and sends its submissions through the [Resend](https://resend.com) API.

Create a `.env.local` file (see `.env.example`) with:

```bash
RESEND_API_KEY=re_...
AULA_EXPERIMENTAL_TO_EMAIL="geral@balletvita.pt"
AULA_EXPERIMENTAL_FROM_EMAIL="Balletvita <no-reply@balletvita.pt>"
```

`AULA_EXPERIMENTAL_FROM_EMAIL` must use a domain verified in Resend.

This project uses [`next/font`](https://nextjs.org/docs/app/building-your-application/optimizing/fonts) to automatically optimize and load [Geist](https://vercel.com/font), a new font family for Vercel.
